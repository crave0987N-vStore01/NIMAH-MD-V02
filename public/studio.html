You can use {{name}} (sender name), {{sender}} (number), {{q}} (text after the command).

Step 1 · look something up first (optional)

For services that need two calls (e.g. search first, then fetch details). Step 1 runs first; use its answer in the API address below as {{s1.data.0.slug}}.

{{q}} everything typed after the command · {{arg1}} {{arg2}} single words · {{arg2|480}} with a default · {{key:NAME}} a saved key · {{name}} {{sender}}

Use fields from the API answer like {{data.title}}. Run a test below and tap a field to add it.
